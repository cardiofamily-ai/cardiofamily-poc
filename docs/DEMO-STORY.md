# CardioFamily Demo Story

## Demo Family

Create a compelling synthetic HCM family.

Proband:

Sarah Janssens
Age 42
HCM phenotype
Synthetic MYBPC3 variant
Pathogenic classification

Family should contain approximately 6–8 relatives.

Include examples of:

- genotype-positive relative
- genotype-negative relative
- untested sibling
- phenotype-positive relative
- young relative under surveillance
- relative with overdue screening
- relative awaiting cascade testing

## Demo Narrative

### Scene 1 — Command Centre

Show:

"Who needs attention now?"

Highlight:
- overdue surveillance
- testing gaps
- clinician reviews

### Scene 2 — Family Workspace

Open Sarah's family.

Immediately show where care gaps exist.

### Scene 3 — Relative

Open one genotype-positive relative.

Show:

RISK
NEXT ACTION
GENETIC INTERPRETATION

Explain WHY an action exists.

### Scene 4 — Reclassification Event

Demonstrate a second synthetic family with a variant whose interpretation
changes.

Example:

VUS
→ laboratory-confirmed Likely Pathogenic

Do not perform a real variant classification algorithm.

### Scene 5 — Impact

CardioFamily should calculate/display:

- which relatives may now need clinician review
- whose cascade-testing status may need reconsideration
- which pathways may be affected

### Scene 6 — Close

Return to Command Centre.

Message:

"One cardiac genetic diagnosis should trigger care for an entire family.
CardioFamily closes the loop."
