# CardioFamily POC Scope

## Goal

Build an interactive HCM demonstration suitable for:

- investors
- clinicians
- potential pilot centres

## Required POC Experiences

### 1. Clinical Command Centre

Show:
- families requiring attention
- overdue actions
- relatives awaiting cascade testing
- upcoming surveillance
- unresolved clinician reviews
- reclassification events

### 2. Family Workspace

Show a family as a connected care unit.

The user should quickly understand:
- proband
- relationships
- genotype status
- phenotype status
- testing status
- surveillance state
- outstanding actions

### 3. Relative Profile

Prominently show:

RISK
NEXT ACTION
GENETIC INTERPRETATION

Also show:
- relationship to proband
- testing history
- surveillance history
- action history

### 4. Family Action Engine

Demonstrate transparent WHO / WHAT / WHEN / WHY actions.

### 5. Reclassification Impact

Simulate a variant interpretation change.

Show:
- affected family members
- why each person may be affected
- potential workflow consequence
- clinician-review status

### 6. Relative Portal Preview

Simple demonstration of what an invited relative could eventually see.

This is a UI simulation only.

## Explicitly Out of Scope

- real patient data
- production authentication
- hospital integration
- FHIR
- laboratory integration
- real consent workflows
- predictive ML
- CardioFamily Twin
- real ACMG classification
- genomic sequencing pipelines
- medical-device claims
